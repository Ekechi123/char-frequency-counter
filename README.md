# Overview 

This project provides a C++ program to identify the most frequent character in a string and return its frequency. The input string is automatically converted to uppercase for consistency.

## Features

- 🔍 Find the most frequent character in a string.
- 🔠 Automatically converts input to uppercase before analysis.
- 📊 Returns the frequency of the most common character.
